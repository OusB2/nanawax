# NANAWAX — première page

Next.js 14 (App Router) · React · Tailwind CSS · Framer Motion · GSAP

## Lancer le site
```bash
npm install
npm run dev
```
Puis ouvrir http://localhost:3000

## Où modifier
- `lib/data.js` : catégories, produits et prix (FCFA)
- `components/WaxPattern.jsx` : motifs wax en SVG (à remplacer par de vraies photos)
- `public/logo.png` : logo d'origine
